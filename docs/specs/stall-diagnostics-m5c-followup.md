## F1. Откат при SIGTERM/SIGINT

`scripts/mutate-stall.js`: обработчик `exit` не срабатывает, если процесс получил SIGTERM во
время `spawnSync`. Ревьюер воспроизвёл это в Docker `node:24`: применённая мутация остаётся
в `src/`. Повесь явные обработчики `SIGTERM` и `SIGINT`: они делают `restore()` и
завершают процесс с ненулевым кодом. Тест в `scripts/test-stall-gate.js`: запустить ворота,
дождаться, пока мутация ляжет, послать SIGTERM и проверить, что хеши `src/` совпадают с
исходными. Тест должен быть детерминированным, без гонок по времени: например, синхронизация
по строке вывода или по специальной переменной окружения, которая подвешивает ворота после
применения мутации.

## F2. M54 не эквивалентна

После M5b `typeAndSubmit` подтверждает отправку по `capture.postAccepted`. Мутация M54
(`postAccepted` только при `status > 200`) при POST 200 без DOM-подтверждения даёт две
отправки вместо одной; ревьюер это воспроизвёл. Убери M54 из списка эквивалентных,
включи её в каталог ворот и убедись, что она убивается своим ассертом. Если существующий
тест D1 её не ловит, доработай его: POST именно со статусом 200.
